# おばけあそび

幼稚園のお化け屋敷（自治会イベント）の **待ち列・出口の休憩スペース** で遊ぶ、
QRコードから立ち上がるスマホゲーム集です。メニューから3つのゲームを選べます。

- アプリのインストール不要（ブラウザで開くだけ）
- 1回 **30秒〜1分程度** で終わる（列が進んだら「←」ボタンでいつでもやめられる）
- 文字が読めない園児（3〜6歳）でも遊べる。ボタンは大きく、文字は最小限
- 個人情報を一切集めない。スコアはスマホの中だけに保存され、外部に送信しません

---

## 3つのゲーム

| ゲーム | あそびかた | 向いている子 |
|---|---|---|
| **おばけタッチ** | 30秒間、出てきたおばけを指でタッチ。しろ=1点／火の玉=2点／かぼちゃ=3点。残り15秒からは大発生 | 4歳〜。反射神経系 |
| **なかまはずれ** | 並んだおばけの中で1匹だけ違うおばけをタップ。全10問で、後半ほど数が増え（6→9→12→16匹）、違いも小さくなる（別のおばけ → 2種類まざり → 傾き・大きさ・色の違い）。時間制限なし | 4歳〜。じっくり見て選べる観察系 |
| **おばけあわせ** | 8枚のカードをめくって同じおばけのペアをそろえる神経衰弱。タイマーなし。まちがいが少ないほど高得点 | 4歳〜。保護者と一緒に考えられる |

どのゲームも失敗・減点の概念はなく、終わると必ず称号がもらえます。
音は最初オフです。画面右上のスピーカーボタンで切り替えられます。

## 開発者むけ

### 1. パソコンで動かして確認する

このフォルダの中で、次のどちらかを実行します。

```
python -m http.server 8000
```

Pythonがない場合（Node.jsが入っていれば）:

```
npx serve .
```

ブラウザで `http://localhost:8000` を開きます。
スマホ表示で見たいときは、`F12` キー → 左上のスマホのアイコンをクリックします。

> ファイルをダブルクリックして開く（`file://`）方法は、
> オフライン機能が動かないため避けてください。

### 2. 公開する（GitHub Pages）

1. GitHubで新しいリポジトリを作り、このフォルダの中身をプッシュする
2. リポジトリの `Settings` → 左メニューの `Pages` を開く
3. `Source` で `Deploy from a branch` を選び、ブランチを `main`（または `master`）、フォルダを `/ (root)` にして `Save`
4. 数分待つと `https://ユーザー名.github.io/リポジトリ名/` で開けるようになる

### 3. QRコードを作る

1. `tools\qr.html` をブラウザで開く
2. 手順2で確定したURLを入力して「つくる」を押す
3. `Ctrl + P` で印刷（A4）。**QRは3cm角以上**にする

### 4. ファイルの構成

```
index.html          画面の骨組みと、おばけの絵（SVG）
style.css           見た目
js/app.js           共通の仕組み（メニュー・タイマー・得点・結果画面）
js/games/touch.js   ゲーム1 おばけタッチ
js/games/odd.js     ゲーム2 なかまはずれ
js/games/match.js   ゲーム3 おばけあわせ
js/ghosts.js        おばけの種類と出現位置
js/sound.js         効果音（音声ファイル不要）
js/storage.js       ゲームごとの最高得点の保存
sw.js               オフライン対応
tools/qr.html       QRポスター作成ページ
```

### 5. ゲームを調整する・増やす

- 各ゲームのファイル先頭にある大文字の変数（`SPAWN_NORMAL` など）を変えると難しさを調整できます
- 称号の点数は各ファイルの `ranks` で変えられます
- **新しいゲームを追加する**には、`js/games/` に新しいファイルを作って `App.registerGame({...})` を呼び、
  `index.html` の末尾の `<script>` 一覧と `sw.js` の `FILES` に追加します。
  書き方の見本は `js/games/touch.js` の先頭コメントにあります

> **公開後にファイルを直したときは、`sw.js` の `CACHE_NAME` の `v5` を `v6` に増やしてください。**
> 増やさないと、一度アクセスした人のスマホに古い画面が表示され続けます。
